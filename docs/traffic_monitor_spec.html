Traffic Monitor Desktop

Ứng dụng desktop giám sát giao thông: phát hiện phương tiện bằng YOLO, theo vết bằng ByteTrack, đếm lượt IN/OUT qua LineZone, ước lượng tốc độ bằng biến đổi phối cảnh, phát hiện vi phạm tốc độ và xuất video có chú thích cùng báo cáo JSON. Tài liệu này là bản đặc tả chuẩn hóa từ Readme.md, dùng làm căn cứ triển khai và nghiệm thu.

      Pipeline xử lý một frame

      Thứ tự bắt buộc, thực thi trong FrameProcessor.process() trên worker thread. UI không thực hiện bước nào trong số này.

      1. Framenp.ndarray (H,W,3) BGRVideoProcessor.read_frame()
      2. Detectionsv.DetectionsYOLO → from_ultralytics()
      3. Filteringconf ≥ 0.30, class ∈ {2,3,5,7}filter_detections()
      4. Tracking+ tracker_idByteTrack → DetectionsSmoother
      5. Countingcrossed_in, crossed_outLineZone.trigger() một lần
      6. Speeddict[int, float] km/htransform → deque → v
      7. Violationdict[int, Violation]speed > limit
      8. Annotationnp.ndarraybox, label, trace, line, overlay
      9. StatisticsTrafficStatisticsget_statistics()
      10. Processed frame→ VideoWriter + signalghi file, gửi về UI
      # app/core/traffic_monitor.py — chỉ điều phối, không chứa thuật toán
def process_frame(self, frame: np.ndarray, frame_index: int) -> DetectionResult:
    detections = self._detector.detect(frame)                 # detect + filter
    detections = self._tracker.update(detections)            # tracker_id + smoothing
    self._counter.count(detections)                           # LineZone.trigger() 1 lần
    anchors = detections.get_anchors_coordinates(sv.Position.BOTTOM_CENTER)
    world = self._speed.transform_points(anchors)
    self._speed.update_track(detections.tracker_id, world, frame_index)
    speeds = {tid: self._speed.get_speed(tid) for tid in detections.tracker_id}
    for tid, cid in zip(detections.tracker_id, detections.class_id):
        self._violations.check(tid, speeds[tid], VEHICLE_CLASSES[cid], frame_index)
    return DetectionResult(frame_index, detections, speeds, self.get_statistics())

      def count(self, detections: sv.Detections) -> tuple[np.ndarray, np.ndarray]:
    """Trigger the line zone once and accumulate per-class counts."""
    crossed_in, crossed_out = self._line_zone.trigger(detections)
    for class_id in detections.class_id[crossed_in]:
        self._class_counts[self._name(class_id)]["in"] += 1
    for class_id in detections.class_id[crossed_out]:
        self._class_counts[self._name(class_id)]["out"] += 1
    return crossed_in, crossed_out

      Gọi trigger() hai lần trong một frame sẽ làm lệch trạng thái nội bộ của LineZone và đếm sai. Đếm theo loại từ mask trả về giúp giữ đúng quy tắc một lần mỗi frame.

      VideoProcessor

      app/pipeline/video_processor.py

      Đọc từng frame bằng cv2.VideoCapture, không nạp cả video vào RAM. Không phụ thuộc Qt: pause/stop dùng threading.Event.

      open(path: Path) -> sv.VideoInfo
      read_frame() -> np.ndarray | None
      process(on_frame: Callable, should_stop: Callable) -> ProcessSummary
      pause / resume() -> None
      stop() -> None
      release() -> None
      def process(self, on_frame: Callable[[np.ndarray, TrafficStatistics, int], None]) -> ProcessSummary:
    """Process frames sequentially until the video ends or stop() is called."""
    try:
        while not self._stop_event.is_set():
            self._resume_event.wait()                 # chặn khi PAUSED, không tốn CPU
            frame = self.read_frame()
            if frame is None:
                return ProcessSummary(completed=True, frames=self._index)
            annotated, stats = self._frame_processor.process(frame, self._index)
            self._writer.write(annotated)
            on_frame(annotated, stats, self._index)
            self._index += 1
        return ProcessSummary(completed=False, frames=self._index)
    finally:
        self.release()                                # luôn đóng capture và writer
